## How to read this

Columns:

- **Claim**: one statement at the local code pin `260b4c2`, unless explicitly historical.
- **Artifact**: the file, test, or report that supports it. Symbols and test names are preferred to stale line numbers. A test is named as `file::test`.
- **Rev**: the commit that introduced the behaviour, or the commit a run used. A revision without a newer superseding entry identifies the code or historical run being cited. A merged job is cited by its merge commit and PR number.
- **Evidence**: one of the four categories below.
- **Superseded by / status**: "current" means current in the inspected local snapshot. Issue numbers identify follow-ups; their live GitHub state was not verified.

Evidence categories:

- **software test**: a test in the repo asserts the behaviour.
- **synthetic**: an end-to-end run on generated data (synthetic recordings or scenes).
- **physical measurement**: computed from a real sensor recording. **None of these have tape-measured ground truth** unless the row says so.
- **none yet**: no evidence. The row describes a design, an assumption, a missing piece, or a step that has not happened.

For a "not done" or "does not exist" row, the category describes the evidence for the missing capability. That is usually "none yet". A row whose artifact is marked "(local)" cannot be checked from a clone of the repo.
